AppCine 

O AppCine foi desenvolvido como atividade da disciplina de Programação e Design para Dispositivos Móveis.

O aplicativo permite pesquisar filmes pela API OMDb, ver suas informações e adicionar aos favoritos. Os filmes favoritos ficam salvos no banco de dados Room, mesmo depois de fechar o aplicativo.

Tecnologias utilizadas

Kotlin, Jetpack Compose, Retrofit, Gson, Room, Navigation Compose, ViewModel, Coroutines e StateFlow.

Como executar

Para executar o projeto, é necessário abrir no Android Studio e configurar uma chave da API OMDb, que pode ser obtida em https://www.omdbapi.com/apikey.aspx.

Depois, basta substituir "digite aqui sua chave gerada no omdb" pela chave no arquivo AppNavigation.kt e executar o aplicativo.
